# 🥟 Momo Shop Website

A simple and beginner-friendly Momo Shop website created as a front-end web development project.

## 📌 About the Project

This project is a food shop website designed for a fictional Momo Shop. 
I created it to practice the fundamentals of HTML and learn how to structure and organize a real-world website.

The website includes sections for the shop, menu, information, and navigation between different parts of the website.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Clean and simple website layout
- Momo shop menu
- Navigation links
- Food images and descriptions
- About/Information section
- Contact section
- Beginner-friendly responsive design

## 🎯 Purpose

The main purpose of this project was to improve my front-end development skills by building a website from scratch.

As a Computer Science student, I am using small projects like this to practice my skills and gradually learn more about web development.

## 📚 What I Learned

While creating this project, I practiced:

- Creating HTML page structure
- Using headings, paragraphs, images, and links
- Creating navigation
- Organizing website sections
- Using CSS for styling and layout
- Building a website from scratch

## 🚀 Future Improvements

I plan to improve this project by adding:
